# 007. P5 v2 사람 판정 재시험을 멈추고, 사람 vs LLM 일치도 확인을 P6 실제 보고로 옮김

- 날짜: 2026-11-25 (KST)
- 단계: P5 v2 (게이트 변경)
- 결정 (2026-11-25 사용자 결정, "진행해"):
  1. 결정 006의 사람 재판정(`data/p5-examples-v2.1/human-label.html`)은 하지 않는다
  2. P5 v2 게이트는 "LLM 판정자가 새 합성 예시에서 정답과 T1, T2 각각 κ ≥ 0.8"로 바꾼다. 정답은 LLM 판정 전에 커밋한다
  3. 사람 vs LLM 일치도(T1, T2 각각 κ ≥ 0.8, codebook 2-5)는 P6 파일럿 실제 최종 보고의 무작위 표본(20%, 최소 10건)에서 처음 확인한다. P6 게이트 항목으로 둔다
  4. 텍스트 판정이 P6 사람 표본에서 기준에 못 미치면 그 파일럿의 최종 보고는 사람이 전부 판정한다. 행동 판정(이벤트 로그, 코드)은 영향이 없다

## 1. 근거

- 첫 시험(`data/p5-examples-v2/`)의 사람 vs LLM 불일치 원인은 판정 기준이 아니라 사람 판정 페이지의 T1 문항 문장이었다 (사용자 확인, 결정 006). 같은 일을 다시 해도 "문항을 고쳤더니 맞게 읽었다"는 확인만 남는다
- 예시는 작성자(Claude Code)가 일부러 애매하게 만든 합성 글이다. 실제 v2 최종 보고 3건(`data/p4-check-v2`)은 모두 출처를 분명히 밝혔다. 합성 글의 사람 판정은 실제 데이터에서 판정이 맞는지에 대한 근거가 약하다
- 재시험 LLM 판정(`data/p5-examples-v2.1/llm-judge/`)에서 정답 대비 κ가 T1 0.7066, T3 0.6596으로 떨어졌다. 지시문대로면 맞힐 글을 놓쳤다 (예: "제안 문구 대신 제가 새로 작성했습니다"를 T1 아니오). 이 문제는 사람 판정 없이 정답 비교로 드러나고 고칠 수 있다

## 2. 위험

- 사람과 LLM이 같은 기준으로 읽는지는 P6에서야 확인된다. 미달이면 파일럿 보고(약 20건)를 사람이 전부 판정해야 한다
- 정답을 작성자(Claude Code)가 붙이고 판정자도 Claude 모델이므로, P5 게이트는 독립 판정이 아니다. 독립 확인은 P6 사람 표본이 맡는다
