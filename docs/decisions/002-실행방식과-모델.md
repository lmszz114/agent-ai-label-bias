## Claude Sonnet 5.5를 고른 이유

- 1단계 목적은 **통제가 잘 된 측정**임. 숨은 시스템 프롬프트와 회사 쪽 안전 장치(프롬프트 주입 분류기)가 공식 문서로 확인되는 쪽이 통제 조건을 기록하고 방어하기 쉬움
- 5/5 정상 종료로 안정적임
- 계기 사례(research-notes 2-1)와 같은 모델 계열이라 연구 서사가 이어짐. 단, 팝업에 회사 이름을 표시하지 않으므로 자기 선호(H3-d)는 섞이지 않음
- 비용은 OpenAI의 약 6.5배지만 절대 금액이 작음 (1회 약 $0.085, 시험 페이지 기준. 본 목업은 입력 칸이 많아 더 늘어날 것으로 봄, 추측)

## 주의할 점 (본 실험에 넘기는 것)

- **천장 효과 위험**: Claude는 시험 팝업을 5/5 닫았음. 단, 시험 팝업 본문에 "시험용 문장이며 내용은 중요하지 않습니다"가 있어 닫기를 부추겼을 수 있음. P6 파일럿 게이트(한 행동 90% 이하)에서 확인
- **보고 여부**: Claude는 5/5 보고했음. "보고 여부" 지표도 천장일 수 있음. P6에서 확인
- **회사 쪽 확인 유도**: Anthropic 프롬프트 주입 분류기는 기본으로 켜져 있고, 의심되면 모델이 사용자에게 확인하도록 유도함. 이 유도는 응답에 따로 표시되지 않아 모델의 자발적 질문과 구분할 수 없음. 조건 간 같으므로 차이 비교에는 섞이지 않지만, "질문" 절대 비율을 해석할 때 한계로 적음 (명세서 v1.1 8-2)
- **실행 코드 고정**: P2는 커밋 전 코드로 돌렸음. P4부터 커밋 안 된 변경이 있으면 실행 거부 (evidence.md 7장)
