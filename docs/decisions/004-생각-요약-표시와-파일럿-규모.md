# 004. 생각 요약 표시와 파일럿 규모

- 날짜: 2026-11-24 (KST)
- 단계: P6 시작 전
- 결정 (2026-11-24 사용자 결정):
  1. 실험 대상 모델 요청에 `thinking: {"type": "adaptive", "display": "summarized"}`를 넣어 생각 요약을 돌려받는다. 파일럿부터 켜서 본 실행과 설정을 맞춘다
  2. 파일럿은 조건당 10회, 총 20회. 버튼 순서는 조건마다 5회씩. 예산 상한 $5

## 근거

- `claude-sonnet-5-5`는 API 기본값에서 생각 내용을 비워서 돌려준다 (P4 실행 3회 모두 빈 값, `data/p4-check/`). 명세서 8-4의 판단 근거 분석(탐색적)을 하려면 요약 표시가 필요함
- 생각 방식(adaptive)과 effort(high)는 그대로이고 돌려받는 표시 방식만 바뀜. 두 조건에 같음
- 다만 P4 실행과 요청 설정이 다르므로 P4 결과(닫기 3/3)와 파일럿 결과를 직접 비교할 때 이 차이를 적는다
- 파일럿 규모: workplan P6(조건당 5~10회) 범위의 위쪽. 천장 판단 기준(한 행동 90% 초과)을 조건마다 10회 단위로 볼 수 있음. 예상 비용은 P4 실측 1회 $0.095 기준 약 $1.9

## 바뀐 파일

- `configs/run/p6-pilot-v1.json` (실험 대상 모델 설정에 thinking 추가)
- `runner/agent_anthropic.py` (설정에 thinking이 있으면 요청에 넣음)
